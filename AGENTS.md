# AGENTS.md

## Where things live

- `.github/projects.json` is the single source of truth for project categories and descriptions. It feeds this README and the website (maxgfr.github.io).
- The `PROJECTS` block in `README.md` is generated by `.github/scripts/generate-readme.mjs`. Never edit it by hand: edit `projects.json`, then run `node .github/scripts/generate-readme.mjs` (set `GITHUB_TOKEN` to avoid rate limits).

## Writing descriptions

Each project has `{ "fr": "...", "en": "..." }`. Keep them short:

- One sentence, about 60 characters, 120 max.
- Say what it does for the user, not how it is built. No feature lists, no algorithm names, no version numbers.
- At most one detail that sets it apart (e.g. "in the browser", "no account", "(Rust)").
- No em dash (`—`) or en dash (`–`). Use `:`, `,` or a period.
- FR and EN say the same thing. FR uses "tu".

Examples:

- `Encrypted pastebin in the browser, no account.`
- `Pastebin chiffré dans le navigateur, sans compte.`
